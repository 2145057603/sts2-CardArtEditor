# CardArtEditor

《杀戮尖塔 2》卡面管理器 Mod。

这个项目的目标不是只替换单张卡图，而是提供一整套卡面管理流程，包括单卡替换、卡包导入、右侧快速选图、批量替换任务、发布包导入与一键应用。

## 当前功能

- 单卡替换
- 恢复默认卡图
- 卡包浏览与管理
- 素材包导入
- 发布包导入
- 右侧选图栏快速换图
- 批量替换任务流
- 发布包一键替换
- 快捷键自定义
- 安装器脚本安装 / 卸载

## 默认快捷键

- `F7`：打开 / 关闭主界面
- `Ctrl + R`：恢复当前卡牌默认图片
- `Ctrl + B`：打开 / 关闭卡包浏览
- `Ctrl + P`：打开 / 关闭右侧选图栏

这些快捷键后续都可以在游戏内设置界面里修改。

## 安装说明

如果你是普通玩家，推荐直接使用仓库里的安装器：

- 打开 `安装器/`
- 运行 `卡面修改器安装卸载脚本.bat`
- 按菜单选择安装或卸载

安装器会负责把模组文件复制到游戏的 `mods` 目录。
